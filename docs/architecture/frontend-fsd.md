# Архітектура фронтенду: Feature-Sliced Design (FSD)

Клієнтська частина платформи **VIRaTeC** спроєктована за сучасною методологією **Feature-Sliced Design (FSD)** на базі React 19, Vite та TypeScript.

## Шари FSD

```
src/
├── app/         # Ініціалізація, провайдери, глобальні стилі, роутер
├── pages/       # Композиція сторінок (Home, Research, Projects, Events, Community)
├── widgets/     # Самостійні UI-блоки (Header, Footer, HeroBanner)
├── features/    # Користувацькі сценарії з бізнес-цінністю (AuthByEmail, FilterProjects)
├── entities/    # Бізнес-сутності предметної області (User, ResearchPaper, Project, Event)
└── shared/      # Перевикористовуваний код: UI-кит, API-клієнт, конфіги, утиліти
```

## Ключові правила

1. **Односпрямований потік залежностей**: Модулі вищого шару можуть імпортувати лише модулі з нижчих шарів:
   `app -> pages -> widgets -> features -> entities -> shared`.
2. **Слайси та сегменти**: Кожен слайс розбивається на сегменти `ui/`, `model/`, `api/`, `lib/`.
3. **Публічний інтерфейс**: Експорт з будь-якого слайса здійснюється через `index.ts`. Прямий доступ до внутрішніх файлів заборонено.

# Модульна архітектура бекенду VIRaTeC

Бекенд побудований на **NestJS** (із Fastify адаптером для максимальної пропускної здатності) та **Prisma ORM**.

## Принципи побудови

1. **Ізоляція доменів**: Кожен модуль (`auth`, `users`, `research`, `projects`, `events`, `community`, `health`) повністю інкапсулює власні:
   - Контролери (`*.controller.ts`)
   - Сервіси бізнес-логіки (`*.service.ts`)
   - Схеми та об'єкти передачі даних (`dto/*.dto.ts`)
   - Модульні визначення (`*.module.ts`)
2. **Спільні контракти**: Загальні типи, інтерфейси та валідаційні схеми виносяться у `packages/contracts`, що забезпечує наскрізну типізацію між бекендом та фронтендом.
3. **Обробка помилок**: Глобальний фільтр `AllExceptionsFilter` уніфікує формат відповідей при помилках.
4. **Трансформація даних**: `TransformInterceptor` обгортає всі успішні відповіді у єдиний JSON-конверт `{ data: ... }`.
5. **Документування**: Автоматична генерація інтерактивної документації OpenAPI/Swagger за маршрутом `/docs`.
